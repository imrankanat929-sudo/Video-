# THE TALL MAN (Slenderman) — monster reference

**Source of truth:** `didao_engine/characters.py → draw_slender()` (height `SLENDER_H = 2.95 m`).

* Very tall and thin; legs and arms abnormally long (hands reach the knees).
* White, completely featureless face (no eyes, no mouth — ever).
* Black classic suit, white shirt, dark tie; pale long-fingered hands.
* Animation rules: slow, unnatural; mostly stands still; head tilts in jerky steps; never runs.
* Disappearance = 0.5 s glitch (horizontal slice displacement + static sound), then gone.
* Escalation in Episode 1: far away in fog (clip 3) → at the treeline near the tent (7–8) → **three identical copies** (12).
  Future episodes keep escalating presence; never change design or proportions.
