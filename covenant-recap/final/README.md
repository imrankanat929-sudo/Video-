# Финальные версии (из трейлера)

- `covenant_recap_ru.mp4`, `covenant_recap_en.mp4` — 1080×1920, 30 fps, H.264, ровно 60.0 с, громкость −13 LUFS.
- `cover_ru.jpg`, `cover_en.jpg` — обложки.

Источник кадров: официальный трейлер (854×480), 40 планов, полосы и значок «18+» убраны.
Стиль: крупный заголовок сверху, красные плашки-теги по сценам, субтитры с жёлтыми ключевыми словами, наезд/отъезд камеры, песочно-оливковая цветокоррекция.

Музыка — временная заглушка (синтезированный дрон + удары на сменах сцен). Перед публикацией заменить на лицензионный трек.

Пересборка: `python3 tools/build.py ru|en` (нужен трейлер в `trailer/trailer.mp4` рядом со скриптом; в репозиторий не кладётся).
