# NOXARGENT_STUDIO

Подготовка Windows к производству AI-сериалов.

1. Скачайте репозиторий (Code → Download ZIP) и распакуйте.
2. Дважды щёлкните `setup_windows.bat`.

Скрипт сам установит Python и FFmpeg (через winget), библиотеки pillow, numpy, opencv-python, faster-whisper, создаст на Рабочем столе папку `NOXARGENT_STUDIO` и отрендерит тест `test.mp4` (10 с, 1920×1080, 30 FPS).
