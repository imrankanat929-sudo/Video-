# HIDE & HUSTLE — Leather Brand Starter Kit

Launch blueprint and ready-to-use storefront for a teen-run premium leather bag brand.

- **[BLUEPRINT.md](BLUEPRINT.md)** — brand strategy & USP, pricing and margin math, TikTok script matrix, Day 1 → Day 30 roadmap.
- **[site/](site/)** — mobile-first landing page (HTML + Tailwind) with product catalog, cart and WhatsApp/Telegram checkout.

## Quick start

1. Edit `site/config.js`: WhatsApp number, Telegram username, products, prices, photos.
2. Open `site/index.html` in a browser to preview.
3. Publish for free: drag the `site/` folder into Netlify Drop, or use GitHub Pages.
