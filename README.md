# HUMAN MIND — Episode 01: Сила маленьких привычек / The Power of Small Habits

Минималистичный кинематографичный 2D-фильм (~1:56, 1920×1080, 30 fps) по идеям книги
Джеймса Клира «Атомные привычки». Вся анимация — оригинальная, генерируется кодом
(Python + Cairo): белый светящийся стикмен на чёрном фоне, мягкое свечение, плавные
движения камеры.

## Сцены

1. **Два человека — два будущего** — огромная лестница к свету; один уходит, второй делает шаг.
2. **Ожидание идеального момента** — «с понедельника», листы календаря улетают, книга, коврик и чек-лист не тронуты.
3. **Начни с малого** — один кубик превращается в лестницу; несколько страниц; несколько минут движения; одна привычка ✓.
4. **Маленькие действия складываются** — каждый день новая ступенька, счётчик дней до 365, time-lapse.
5. **Человек, которым ты становишься** — зеркало, воспоминания о повторённых действиях, уверенная осанка.
6. **Финал** — вершина лестницы, камера отъезжает, вопрос зрителю, логотип HUMAN MIND, затемнение.

## Звук

* Озвучка всегда громче фона (~14 дБ над музыкой во время речи; музыка «приседает» под голос через sidechain-компрессию).
* Музыка: LoVibe — *A Good Man With A Broken Heart* (предоставлена), естественная концовка трека совпадает с финалом.
* Процедурные SFX: шаги, перелистывание календаря, открытие книги, карандаш, тиканье часов, переходы, финальный удар.
* Громкость мастера ≈ −14 LUFS (стандарт YouTube).

## Пересборка

```bash
pip install pycairo numpy scipy pillow soundfile faster-whisper kokoro-onnx
cd src
python timeline.py ru && python timeline.py en   # тайминг озвучки (нужны vo.mp3, ru_lines.txt/en_lines.txt и модели Kokoro в рабочей папке)
python sfx.py ru && python mix.py ru ../assets/music_lovibe_a_good_man_with_a_broken_heart.mp3
python render.py ru chunk 0 3480 ../build/chunks/ru_0.mp4
python thumb.py en ../output/thumbnail_en.png
```

`build/cues_*.json` хранит точные тайминги каждого предложения и слова — по ним синхронизируются
анимация, субтитры и звуковые эффекты.
