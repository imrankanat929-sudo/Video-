# «А ЧТО, ЕСЛИ…?» — Серия №1: «А что, если упадёт атомная бомба?»

2D-хоррор-видео, полностью нарисованное и озвученное (SFX + музыка) **кодом** на Python, синхронизированное с готовой озвучкой ElevenLabs.

|---|---|
| `what_if_ep1_atomic.mp4` | Финальное видео 1920×1080 (16:9), 24 fps, с вшитыми субтитрами |
| `what_if_ep1_atomic_nosubs.mp4` | То же видео без субтитров |

Длительность ≈ 4:05: озвучка 3:39 + финальный выбор А/Б держится на экране ~26 с.

Тимур (тёмные волосы, чёрная толстовка, серые брюки, тёмные кроссовки) рисуется одной функцией (`src/character.py`) во всех сценах — внешность не меняется. Лиц крупным планом и графических последствий нет.

## Синхронизация с озвучкой ElevenLabs

1. Положите новую озвучку в `assets/voiceover.mp3`.
2. Распознайте её с таймкодами слов: `python tools/transcribe.py` → `sync/transcript.json`.
3. Метки сцен в `sync/cues.json` — это **фразы** из текста. Они автоматически находятся в транскрипте, и все сцены, переходы, звуки и субтитры сдвигаются под новую озвучку. Проверить: `python -m src.cues`.

## Сборка

```bash
pip install -r requirements.txt     # + ffmpeg в системе
python -m src.audio                  # звук: SFX + музыка + озвучка -> build/mix.wav
python -m src.thumbnail              # превью
python -m src.render                 # видео 16:9 (все ядра CPU), ~20–30 мин
python -m src.vertical               # версия 9:16 для TikTok + обложка (после render)
python -m src.preview 37.4 120       # быстрые кадры для проверки -> build/
```

## Структура

- `src/gfx.py` — слои, камера (зум/панорама/тряска), параллакс по глубине, свет, плёночное зерно, виньетка, грейдинг
- `src/sets.py` — декорации: город, квартира, телефон, лестница, улица, убежище, коридор, дверь
- `src/character.py` — Тимур и безликие силуэты людей
- `src/shots.py` — сцены по таймлайну и переходы (склейка / наплыв / затемнение)
- `src/audio.py` — синтез звуков и музыки, радиофильтр, дакинг под голос, сведение
- `src/subtitles.py` — отдельный слой субтитров (SRT + стилизованный ASS)
- `src/render.py` — параллельный рендер и финальная сборка
