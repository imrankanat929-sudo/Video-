# Чёрная смерть — история великой чумы

Короткий исторический документальный ролик (90 сек) в плоском 2D-стиле: тёмная палитра, объёмный свет, туман, движения камеры, анимированные исторические карты.

## Готовые файлы (`output/`)

| Файл | Что это |
|---|---|
| `black_death_ru.mp4` | Видео, русская озвучка + русские субтитры. 1920×1080, 30 fps, 90 с |
| `black_death_en.mp4` | Видео, английская озвучка + английские субтитры |

## Сцены (RU / EN — тайминг чуть отличается под длину фраз)

1. **00:00** Средневековый город вечером: камера спускается с крыш на пустеющую улицу.
2. **00:12** Мальчик у окна со свечой; огни в городе гаснут, свеча гаснет на «Чёрной смерти».
3. **00:21** Центральная Азия: горы, озеро Иссык-Куль, юрты, караван → карта с выделенной Центральной Азией.
4. **00:30** Порт Каффа на Чёрном море → карта: маршруты рисуются с востока на запад, затем по ним «течёт» красная эпидемия.
5. **00:43** 1347 — корабль ночью приходит в Мессину → Европа 1348: закрытые рынки, жители в окнах, лекарь с фонарём → лекарь при свече.
6. **00:57** Карта Европы темнеет 1347→1351, «25–50 млн погибших, ≈30–50 % населения».
7. **01:03** Пустая улица: заколоченные двери, вороны, ветер, рассвет.
8. **01:14** Камера поднимается над городом → «ЧЁРНАЯ СМЕРТЬ» → затемнение → «Эпидемия, изменившая историю человечества».

## Исходники (`source/`)

Всё нарисовано и озвучено кодом, без стоковых материалов:
- `render/` — отрисовка кадров (Node + @napi-rs/canvas), карты по данным Natural Earth (world-atlas).
- `audio.py` — музыка и звуки синтезированы (струнные пэды, колокола, ветер, волны, чайки, вороны, шаги), микширование с приглушением музыки под голос.
- `prep.py`, `timeline.json` — расстановка фраз озвучки по сценам и субтитры (распознаны Whisper, исправлены вручную).
- `build.sh` — полная пересборка.
