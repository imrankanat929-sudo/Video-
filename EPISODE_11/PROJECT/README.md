# Episode 11 — "What if people could read each other's minds?"

Everything in this episode is generated by code in this folder: characters, backgrounds, animation,
music, sound effects, subtitles and the final edit. Nothing is drawn by hand, so any change is a re-render.

## Output
| File | What |
|---|---|
| `RU_VERSION/final_video_ru.mp4` | Russian version, 1080×1920, 30 fps, ~2:32, burned-in subtitles |
| `EN_VERSION/final_video_en.mp4` | English version, 1080×1920, 30 fps, ~2:35, burned-in subtitles |
| `*/preview_9x16_*.png` | 9:16 preview (thumbnail) per language |
| `*/subtitles_*.srt` | separate subtitle files |
| `*/voiceover_*.mp3` | narration used in each version |
| `CHARACTERS/` | reference sheets for the hero and the best friend (used by every scene) |
| `SCENES/` | one still per shot (29 shots) |
| `AUDIO/music`, `AUDIO/sound_effects` | music bed and sound-effects track per language |

## Voice
* **RU** — the supplied voiceover (`Paradigm Eleven v3`), unchanged. Scene timing follows it.
* **EN** — the supplied English file narrates a *different* story ("nobody remembers you"), so it could not be
  used for this episode. The English narration is a translation of the RU script (`EN_VERSION/script_en.txt`),
  voiced locally with Kokoro TTS (`am_michael`). To use a studio voice instead, record `script_en.txt`
  (e.g. in ElevenLabs) and follow "Replacing the English voice" below.

## Pipeline (run from `PROJECT/`)
```bash
pip install skia-python kokoro-onnx soundfile scipy faster-whisper
python3 tts_en.py <model_dir>                # EN voice + timing_en.json (needs kokoro.onnx + voices.bin)
python3 murmurs.py <model_dir>               # short phrases for the "crowd of thoughts" layer
python3 render.py ru video 0 4 ru_0.mp4      # render chunk 0 of 4 (run 0..3 in parallel)
python3 audio.py ru <voice> <murmurs.npy>    # score + sfx + ducking -> mix_ru.wav
python3 subs.py ru                           # SRT + ASS subtitles
./assemble.sh ru <chunk_dir>                 # concat + subtitles + audio -> final mp4
python3 thumb.py                             # previews
python3 sheet.py                             # character sheets
```
* `engine.py` – drawing primitives, characters (hero / friend / extras), thought bubbles, rings, lighting.
* `scenes.py` – 29 shots, camera moves and the timeline. Shot boundaries are tied to sentence start times
  (`timing_*_full.json`), so a new voiceover re-syncs the whole edit automatically.
* `audio.py` – procedural score: mysterious pad → school tension → anxious pulse (day 3) → stronger pulse +
  riser (day 5) → hard cut to silence (day 7) → low boom and drone after the friend's line. Music is ducked under
  the narrator; loudness is normalised to −14 LUFS.

## Replacing the English voice
1. Save the new narration as `EN_VERSION/voiceover_en.mp3`.
2. Get sentence times: transcribe with faster-whisper (see `timing_ru_full.json` for the format: 34 sentence
   starts `S`, ends `E`, and subtitle lines `subs`) and write `timing_en_full.json`.
3. Re-run render / audio / subs / assemble for `en`.
