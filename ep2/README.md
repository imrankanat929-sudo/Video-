## Сборка

```bash
EP=ep2 python tools/transcribe.py ep2/assets/voiceover.mp3 ep2/sync/transcript.json   # при новой озвучке
EP=ep2 python -m src.cues            # проверить метки
EP=ep2 python -m src.ep2.thumbnail   # превью
EP=ep2 python -m src.render --bitrate 2200k   # звук + субтитры + видео
EP=ep2 python -m src.preview 24.5 142.5       # кадры для проверки
```

Код: `src/ep2/` — `chars.py` (персонажи), `sets.py` (локации), `shots.py` (сцены и таймлайн), `audio.py` (звук),
`subs.py` (субтитры), `thumbnail.py` (превью). Общий движок (камера, параллакс, свет, зерно) — `src/gfx.py`.
