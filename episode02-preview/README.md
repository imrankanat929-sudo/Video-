# HUMAN MIND — Эпизод 02 · превью 9:16

- `HUMAN_MIND_EP02_9x16.mp4` — вертикальный ролик 1080×1920, 30 fps, 1:42 (озвучка 1:35 + финальная заставка)
- `HUMAN_MIND_EP02_cover_9x16.png` — превью (обложка) 9:16

Пересборка: `npm i && ./render_all.sh` (нужны node и ffmpeg).
`timeline.js` — общий тайминг, `render.js` — анимация, `audio.js` — звуковые эффекты.

## Звук
- `voice/ru_voiceover_ep02.mp3` — русская озвучка Эпизода 02 (присланная), идёт с 0:00, все сцены синхронизированы с ней
- `music_lovibe.mp3` — фоновая музыка, автоматически приглушается под голосом
- Пересобрать только звук: `SKIP_VIDEO=1 ./render_all.sh`; другую озвучку: `VOICE=файл SKIP_VIDEO=1 ./render_all.sh`
